# Al Ameen & Muhsina — Nikah Invitation

A responsive, single-page Islamic wedding invitation built with HTML and CSS.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `ameen-muhsina-invitation`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. Share the public URL GitHub Pages provides.

## Before publishing
Please verify the names, family details, phone numbers, Hijri date, venue and timings against the printed invitation. The map button opens a Google Maps search for MMJ Convention Center, Mylapore, Kollam. Confirm the exact venue pin before sharing widely.

The WhatsApp contact button currently opens a chat with the first family contact number shown on the invitation.
